# Fastcoding VN - Frontend Developer Entrance Test

Dự án Landing Page Bất Động Sản **Reanty** được xây dựng 100% bằng **HTML5, CSS3 và JavaScript thuần** (Vanilla) theo đúng thiết kế mẫu Figma.

## 🚀 Tính năng nổi bật
- **100% Pure HTML/CSS/JS**: Không sử dụng framework ngoài (Bootstrap/Tailwind).
- **Responsive Design**: Đầy đủ cho mọi thiết bị (Desktop, iPad/Tablet 1024px, 768px, Smartphone 480px) tách riêng file `css/responsive.css`.
- **Đường dẫn tương đối**: Sử dụng relative paths chuẩn xác trong toàn bộ source code.
- **Font Awesome 6 Icons**: Tích hợp icon vector sắc nét.
- **Tương tác mượt mà**: Click Tabs BĐS (Appartment/Vila/Land), Testimonials Slider chuyển đổi nhận xét khách hàng, Video Modal "How it works", Mobile navigation drawer.

## 📁 Cấu trúc thư mục
```
├── index.html          # File HTML5 semantic
├── css/
│   ├── style.css       # Stylesheet định dạng giao diện gốc
│   └── responsive.css  # Stylesheet responsive cho các breakpoints
├── js/
│   └── main.js         # JavaScript thuần xử lý tương tác
└── README.md
```
